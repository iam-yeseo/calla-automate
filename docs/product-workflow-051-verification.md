# CALLA 0.5.1 상품 편집·등록·조회 개선

검증일: 2026-10-07

## 변경 사항

- 원산지: 대한민국/Korea, 중국/China, 일본/Japan, 미국/USA 드롭다운과 영어 국가명 직접 입력. 등록 값은 `Made in 국가명`. 편집·일괄 설정·원격 수정에서 같은 입력을 사용합니다.
- 가격: 소매 정가/판매가 → 도매 정가 → 도매 베이직/마스터 순서. 도매 정가는 소매 판매가를 따르며 직접 입력 체크로 별도 금액을 저장합니다. 0과 빈 값은 구분됩니다. 설정은 기존 automation JSON에 저장하므로 DB 마이그레이션이 필요하지 않습니다.
- 자동 등록: 현재 리스트에서 등록 가능한 상품 전체선택/해제 및 부분 선택 표시. 완료·미확인 결과의 기존 제외 규칙을 유지합니다.
- 조회: 기본 설정/이미지 설정 탭으로 상세·수정을 구성하고 원시 API 필드 목록을 제거했습니다. 표는 상품번호, 상품/모델명, 판매가, 재고, 노출/판매 5열입니다.
- 이름: 신규 등록은 `goodsNmFl=d`, 원문 `goodsNm`만 전송하며 메인·리스트·상세 상품명은 전송하지 않습니다. 상품명에 포함된 HTML 문자도 기본 상품명 텍스트로 보존합니다. 원격 상품 이름 수정도 기본 방식으로 전환하며 다른 기존 필드는 보존합니다.
- 요청 상품: ID 열을 썸네일로 교체하고 미저장 파일 미리보기도 표시합니다. 10/20/30/50/100개 보기, 기본 20개, 선택값 저장을 지원합니다.
- 탐색: 마우스 옆 버튼 및 Mac ⌘[/⌘]로 뒤로/앞으로 이동합니다. 미저장 초안의 취소/버리기와 열린 모달 보호를 유지합니다.

## 검증

- TypeScript 및 프로덕션 빌드 통과.
- API/도메인 단위 테스트 123개 통과.
- Electron 단위 테스트 6개 통과.
- 웹/Mac 조회·수정·등록 2개 UI 시나리오 통과. 숨겨진 원격 필드 보존과 원산지 저장 포함.
- 기존 일괄 등록·응답 유실 보호·선택 전달·Mac 종합 회귀 6개 UI 시나리오 통과.
- 신규 상품 개선 시나리오 웹/Mac 2개 통과. 25개 상품 페이지 크기 변경, 썸네일 로드, 원산지 및 도매 정가 저장/재열기, 0원 보존, 완료 상품 제외, 실제 CDP 마우스 back/forward 입력, 미저장 취소/버리기/앞으로 복귀 포함.
- 고도몰 쓰기 검증은 격리된 fixture로 수행했습니다. 운영 상품 등록·수정은 실행하지 않았습니다.

# 고도몰 저장 확인과 결과 복구 (2026-10-02)

대상: CALLA for Mac 0.2.7, 실행기 1.0.2, 운영 Worker.

## 변경

- 저장 전에 동일 상품명 검색 결과를 끝까지 읽어 기존 상품번호를 기록한다. 저장 버튼을 한 번 누르기 전에 실제 저장 요청의 응답 수집기를 연결한다.
- 응답에 번호가 없어도 목록과 상세 화면에서 새 상품 하나를 확인한다. 숫자 상품번호, 상품명, 브랜드·제조사, 원산지, 카테고리, 소매·도매 가격, PC·모바일 노출 상태가 일치해야 성공이다.
- 저장 결과 동기화는 최대 3회 시도한다. 응답이 끊기면 서버 상태를 먼저 다시 읽는다. 같은 번호의 성공 기록이 있으면 이어서 완료 상태만 처리한다. 상품 저장은 다시 실행하지 않는다.
- 원래 실행 버전과 상품 정보가 바뀌면 결과를 덮어쓰지 않는다. 실행 버전·저장 시각·사전 목록·경고를 저널에 보관한다.
- `POST /jobs/{id}/reconcile`은 비동기로 기존 저장 결과만 검증·동기화한다. 새 등록과 계정 교체는 처리 중 차단한다. 화면에 **저장 결과 다시 확인**을 제공한다.
- 과거 버전에서 사전 목록과 번호가 사라진 기록은 날짜만으로 추정하지 않는다. 독립적으로 확인한 상품번호와 원래 실행 시간 범위를 대조한다.

# Mac 모달 크기 변경 검증 — 0.2.3

검증일: 2026-10-02. 앱 전용 모달 위치 규칙을 수정했으며 웹용 모달 및 데이터 저장 동작은 변경하지 않았습니다.

## 원인과 수정

기존 앱의 모달은 높이를 820px로 가정한 위쪽 여백과 실제 창 높이에 따른 최대 높이를 함께 사용했습니다. 창이 커지면 두 값의 합이 화면 높이를 넘어서 하단 버튼이 잘렸습니다. 1680×1200 Electron 창에서 중앙 정렬, 화면 내부 배치, 하단 버튼 클릭 가능 여부 검사가 모두 실패하는 것으로 재현했습니다.

고정 높이 가정을 없애고 제목 막대(56px)를 제외한 영역에 `inset`과 자동 여백으로 실제 모달을 중앙 정렬합니다. 최대 높이는 그 영역의 위아래 16px 여백을 남깁니다. 기존 본문 스크롤과 헤더·푸터의 고정 배치를 유지합니다.

## 검증

- `npm run build` 통과: 타입 검사 및 앱 화면 빌드.
- `npm run test:desktop:ui` 통과: 기존 로그인·저장·엑셀·실행기·창 숨기기 검증과 함께 실제 Electron 창 크기 변경 시나리오를 실행했습니다.
- 1680×1200 → 1040×700(최소 크기) → 1440×960으로 모달이 열린 창의 크기를 변경하고, 모달의 중앙 위치·화면 내부 배치·닫기 및 하단 버튼의 좌표와 클릭 가능 여부를 확인했습니다.
- 크기를 먼저 바꾼 뒤 상품 모달을 여는 경우도 확인했습니다.
- 브랜드 선택 중첩 모달에서 검색 결과가 사라져 모달 높이가 작아져도 중앙 정렬을 유지하고, 닫은 뒤 부모 모달이 정상 표시되는지 확인했습니다.
- 창 크기 변경 후 입력한 초안 유지, 본문 끝까지 스크롤한 뒤 하단 버튼 접근을 확인했습니다. 검증 데이터는 별도 모의 서버와 임시 사용자 폴더를 사용합니다.

화면: [큰 창](screenshots/desktop/modal-resized-large.png), [최소 크기 창](screenshots/desktop/modal-resized-small.png), [작은 중첩 모달](screenshots/desktop/modal-resized-nested.png). 큰 창과 작은 창의 결과 이미지를 직접 검토했습니다.

## 적용

코드 서명 검사를 통과한 0.2.3을 `/Users/callam4/Applications/CALLA.app`에 설치했습니다. 이전 버전은 `release/previous/CALLA-0.2.2-before-modal-fix.app`에 보관했습니다. 기존 로그인 파일과 실행기 작업 기록을 보존했습니다.

설치된 앱을 다시 실행해 기존 계정·실행기 연결을 확인하고, 창을 최대화한 뒤 사용자가 문제를 보고한 LMS120 상품 모달을 열었습니다. 실제 화면에서 중앙 배치와 하단의 취소·목록에 반영 버튼 표시를 확인했습니다. 모달을 연 채 창 크기를 복원한 뒤 취소 버튼으로 닫았습니다. 운영 상품 값은 수정하지 않았습니다. 배포용 압축본은 `release/CALLA-0.2.3-mac-arm64.zip`입니다.

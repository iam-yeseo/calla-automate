# 등록 완료 태그 간소화 · 0.6.2

2026-10-15. 리스트의 소매·도매 결과에서 `api_state=verified`인 항목은 초록 완료 태그만 표시한다. 태그 아래 상품번호·등록시각·PC/모바일 상태·오류·안내를 표시하지 않으며, 저장된 결과 데이터는 유지한다. 태그 전체가 기존 몰별 상품 URL로 연결되고 웹에서는 새 탭, Mac 앱에서는 기본 브라우저로 열린다. 상품번호가 없는 완료 결과는 링크 없는 태그를 표시한다. 미확인·확인 중·실패·확인 필요 등의 상세 표시는 유지한다.

## 검증

- TypeScript 검사와 운영 빌드 통과.
- 데스크톱 검사 6/6 통과. 로컬 연결 권한이 제한된 첫 실행 후, 허용된 환경에서 다시 실행했다.
- 운영 웹의 실제 `261015-울프믹스 등록` 리스트에서 소매·도매 결과가 각각 링크 하나만 포함하며 추가 텍스트가 없는 것을 확인했다. 결과 영역 높이 각각 29px. 초록 배경 `rgb(234, 247, 238)`, 초록 글자 `rgb(22, 101, 52)` 유지. 브라우저 오류 로그 없음.
- 소매 태그 클릭으로 `https://www.callamedia.kr/goods/goods_view.php?goodsNo=1000008215`가 새 탭으로 열림을 확인했다.
- 설치 앱에서 기존 로그인과 저장된 리스트를 유지하고 같은 상품의 완료 태그만 표시됨을 확인했다. 도매 태그 활성화로 `https://www.callamedia.co.kr/goods/goods_view.php?goodsNo=1000008306`가 브라우저에서 열리고 해당 상품 제목이 표시됨을 확인했다.
- 웹은 기존 변수를 유지해 배포했다. Worker 버전: `35539db1-9b22-4d9d-b710-33da3658435b`. 운영 HTML과 진입 JS/CSS가 로컬 빌드와 일치하고 `/api/config`는 200을 반환했다.
- 배포 앱과 설치 앱 모두 코드 서명 검증 통과. `app.asar` SHA-256 일치: `2f685a4ee87e16366ae5b6571f35b374c2cdfe37271285eef34b6230edcdb794`.

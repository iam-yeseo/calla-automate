# CALLA-AUTOMATE 0.5.0 디자인 변경 및 검증

기준일: 2026-10-07

## 디자인 기준

[Figma 파일](https://www.figma.com/design/2eInZ8qvqO2kI88cxofumv/?node-id=30-1293)의 `06 · CALLA-AUTOMATE 새 디자인` 페이지 내 실제 화면 프레임·토큰·보조 모달을 기준으로 구현했습니다. Figma 응답은 `design/redesign-050/`에, 원본 SVG와 크기 기록은 `public/assets/figma-050/` 및 `design/redesign-050/assets.json`에 있습니다.

- Pretendard, 배경 `#F7F8FA`, 브랜드 `#F27490`, 활성 배경 `#FFF0F4`, 8/12/16px 모서리.
- 64px 공통 헤더, 260/60px 사이드바, Mac의 32px 네이티브 상단. 작은 Mac 창에서는 축소 사이드바를 기본으로 사용합니다.
- 화면 본문 내부 스크롤과 고정 작업 하단, 최대 높이를 제한한 편집·검토 모달.
- 요청 목록·상세, 상품 편집·이미지/HTML, 등록 검토·진행·결과, 상품 조회·수정 비교, 인덱싱, 카테고리·브랜드·폴더, 동기화, 로그인·가입·승인 대기·계정 관리에 공통 디자인을 적용했습니다.
- Figma의 예시 데이터와 수치를 앱에 넣지 않고 실제 데이터를 유지했습니다. 기존 API에 필요한 추가 결과·확인 항목도 같은 디자인으로 표시합니다.

## 유지한 동작

기존 0.4.0의 고도몰 공식 API·DB·권한 계약은 변경하지 않았습니다. 원문 HTML과 이미지/텍스트 순서, 네 가지 가격의 빈 값과 0 구분, 무한정 판매 기본값과 수량 0, 한국식 날짜, 몰별 독립 결과와 중복 전송 방지를 유지했습니다.

상품 편집은 `목록에 반영` 후 리스트 저장으로 이어집니다. 저장된 선택 상품만 `등록 전 검토`로 이동하며 검토만으로 실제 상품 등록을 실행하지 않습니다. 상품·계정·폴더의 삭제 등 기존 작업은 권한 및 확인 절차를 유지합니다.

스크린샷·검증 JSON·실행 로그: `test-results/redesign-050/`. API 쓰기 검증은 격리된 테스트 응답으로 수행했습니다. 이번 디자인 업데이트에서 운영 고도몰 상품을 등록하거나 수정하지 않았습니다.

- 웹: `https://cauto.yeseo.im`, Worker `calla-automate`, 버전 `554ee376-0f73-45c3-9577-4afa065b2146`. 기존 런타임 환경변수를 보존했습니다.
- 최종 JS: `index-DCZtZpIt.js`, CSS: `index-xm64XSbH.css`. 운영 HTML과 JS/CSS의 바이트가 로컬 최종 빌드와 일치하고 `/api/config`가 정상 응답했습니다. 운영 로그인 화면의 새 디자인도 확인했습니다.
- Mac: `/Users/callam4/Applications/CALLA.app`, 버전 0.5.0. 패키지와 설치본 모두 `codesign --verify --deep --strict` 통과. 설치본과 패키지의 `app.asar` SHA256은 `77b60885a435b84a44c95c8ef126b57c30296ec6b0c0bd2c7536490c4a8660ff`로 일치합니다.
- 배포용 압축 파일: `release/CALLA-0.5.0-mac-arm64.zip`. Apple Silicon/macOS 13 이상용입니다.
- 이전 설치본 백업: `release/backups/CALLA-0.4.0-before-redesign.app`. 사용자 데이터와 암호화 세션 파일은 교체하지 않았습니다.
- Mac 최초 실행의 키체인 확인은 사용자가 직접 완료했습니다. 이후 실제 설치 앱에서 기존 관리자 로그인, 등록 요청 리스트 11개, 기존 리스트 상세 6개 상품, 가격·몰별 분류·무한정 재고·이미지/HTML 설정과 고정 모달 하단의 정상 표시를 확인했습니다. 편집창은 값을 변경하거나 저장하지 않고 취소했으며 기본 목록으로 복귀했습니다. 설치본·릴리스 앱·ZIP의 버전과 서명 및 `app.asar` 일치도 재확인했습니다. 설치 앱의 최종 실행 검증까지 완료되었습니다.

# 모달 및 인터랙션 개선 — 2026-09-30

## 적용 방향

사용자가 제공한 `modal-prompt.md`의 둥근 카드, 아이콘 헤더, 분리된 입력 영역, 세그먼트 탭, 파일 선택 카드를 현재 상품 운영 흐름에 적용했다. 예시의 오디오 콘텐츠나 별도 UI 라이브러리 설치 지시는 옮기지 않았다. 기존 Pretendard, SF 아이콘 자산, 브랜드 컬러 `#F27490`과 흰색 버튼 텍스트를 유지한다.

- 공통 모달: 아이콘 헤더, 스크롤 본문, 고정 푸터, 열기/닫기 전환.
- 상품 편집: 상품 정보·판매 가격·등록 옵션 구획, 이미지 업로드 영역, 슬라이딩 탭 표시.
- 리스트 생성: 리스트 정보와 파일 입력 구획, 선택 파일 카드, 드래그 앤 드롭 처리.
- 전체 화면: 페이지 전환, 통계 카드 등장, 버튼 눌림, 사이드바·목록 행 반응, 알림과 선택 상태 전환.
- 기본 전환 140–280ms, 모달 닫기 160ms. 운영체제의 모션 감소 설정을 반영한다.

## 동작 보존

탭은 방향키와 Home/End로 이동하며 탭을 바꿔도 초안을 유지한다. 취소·Escape·배경 클릭은 동일한 닫기 경로를 사용하고, 중첩 모달의 Escape는 최상위 모달에만 적용된다. 닫은 뒤 기존 트리거로 포커스를 돌려준다. 저장·등록 요청 중에는 입력과 닫기를 제한한다.

상품 저장, 가격, HTML 원문, 등록 완료 상태, 서버 API와 실행기 계약은 변경하지 않았다. 파일을 선택하는 동작과 최종 저장 시 업로드하는 동작도 기존 흐름을 유지한다.

## 검증

- `npm run check`, `npm run build` 통과. 기존 청크 크기 경고는 남아 있다.
- Node 테스트 37개 통과.
- Chrome 데모에서 모달 닫기 애니메이션과 트리거 포커스 복원 확인.
- 브랜드 선택 중첩 모달의 Escape가 부모 편집창을 유지하는지 확인.
- 키보드 탭 이동, 탭 간 초안 유지, 취소 후 원래 상품명 복원 확인.
- 테스트 PNG를 파일 선택기로 선택하여 파일 카드와 저장 시 업로드 안내 확인. 실제 서버 업로드는 하지 않았다.
- 390×844 모바일에서 가로 넘침 없이 본문 스크롤·푸터 유지 확인. 검수 후 화면 크기 설정 복원.
- 기본 버튼 텍스트의 계산된 색상 `rgb(255, 255, 255)` 확인.
- 새로고침 후 브라우저 오류·경고 로그 없음.

드래그 이벤트 구현은 코드로 확인했으며 실제 파일 드래그는 자동 검수하지 않았다. 운영 데이터 쓰기, 고도몰 상품 등록, GitHub 푸시 및 배포는 하지 않았다.

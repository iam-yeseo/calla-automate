# 261012-록스톤 신제품 등록 복구

## 확인한 원인

- 고도몰 검색 및 등록 요청에서 HTTP 530 / Cloudflare 1016을 실제 운영 로그로 확인했다. 외부 API 호스트의 주소 해석 실패이며, 상품 내용 충돌이라는 증거는 없다.
- PSS130 소매는 정상 저장 응답 000 및 상품번호 1000008206이 확인됐지만, 고도몰이 연결 분류 `017007`을 상위 분류를 포함한 `017|017007`로 반환해 앱의 엄격한 문자열 비교가 실패했다.
- LMS120 도매의 최초 요청은 HTTP530/CF1016으로 고도몰에 도달하지 못했다. 실행 요청 Ray: `a49ce07df0119fe4-AMS`, 2026-10-13 17:11:53 KST. 해당 작업은 `ea42b589-477b-42a3-9113-aeaf6fc7e214`다.

## 적용한 수정

- 조회 요청에만 제한된 재시도와 전체 제한시간을 적용했다. 등록·수정 요청은 자동 재전송하지 않는다.
- HTTP 오류에서 검증된 오류 번호와 Ray만 기록하여 원인을 확인할 수 있게 했다. 인증키나 응답 원문은 기록하지 않는다.
- 연결 분류 비교는 요청한 모든 분류가 존재하고, 추가 값이 요청 분류의 상위 분류일 때만 통과한다. 다른 분류나 누락은 계속 거절한다.
- Worker 실행 위치를 서울 인근(`placement.region = aws:ap-northeast-2`)으로 설정했다. 요금제나 인증정보는 변경하지 않았다. 적용 후 고도몰 정상 조회를 확인했으며, 외부 DNS 장애가 영구히 사라진다는 보장은 아니다.
- 기존 PSS130 소매 등록은 재전송 없이 원래 작업의 조회 검증으로 복구했다.
- LMS120 최초 도매 작업은 실행 경로 변경 후 고유 코드 조회 3회 및 17:17:18 KST 검색 전체 0건을 확인했다. 원본 실패 로그와 대조하고, 작업·연결·등록 상태 및 갱신 시각을 잠금과 조건으로 보호한 기존 완료 RPC를 통해 해당 작업만 실패로 확정하여 재검토를 허용했다.

## 배포

- 최종 Worker: `dd32decd-e781-48b1-a636-5e1d30d72520`
- `--keep-vars` 적용, 기존 비밀값과 설정 유지.
- 서버 수정으로 기존 웹 및 설치된 CALLA 0.5.3 앱에 적용.

## 검증

- 전체 테스트 145개 중 144개 통과. 나머지 Workers 런타임 테스트는 제한 환경의 로컬 포트 권한 오류였으며, 허용 환경에서 재실행하여 통과했다.
- 추가 응답 지연 및 카테고리 회귀 테스트 17개와 타입 검사 통과.
- 실제 재조회 결과와 등록·연결·작업 상태를 대조한 12건 검증 모두 통과. 같은 몰 상품번호·고유 코드·성공 등록 기록의 중복 및 미확인 작업은 0건이다.
- 완료 표시를 정상 앱 화면에서 6개 모두 저장했다. 마지막 DB 확인: 상품 6개, 완료 6개, 등록 성공 12건. 설치된 앱의 ‘등록 완료 리스트’에서 `261012-록스톤 신제품 · 6개 작업 완료`를 확인했다.

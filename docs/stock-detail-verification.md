## 동작과 저장 계약

- 상품 기본 설정에 판매 재고와 상품 재고를 추가했습니다. 기본값은 `unlimited`와 `0`이며 무한정 판매에서는 수량 입력을 비활성화합니다. 재고량에 따름에서는 0 이상의 정수만 허용합니다.
- 고도몰 필드는 실제 관리자 화면에서 읽어 확인했습니다. `stockFl=n`은 무한정 판매, `stockFl=y`는 재고량에 따름이며 수량 필드는 `stockCnt`입니다. 무한정 판매에서 실행기는 수량 필드를 수정하지 않습니다.
- 상품 이미지 설정의 상세페이지 이미지에 텍스트 추가 버튼과 이미지·텍스트별 위·아래 이동 버튼을 추가했습니다. 원문 코드의 대소문자, 공백, 줄바꿈, 태그, 엔티티를 그대로 보관합니다. 편집 화면에서 코드를 실행하지 않습니다.
- `automation.stock`과 순서가 있는 `automation.detailBlocks`에 저장합니다. 기존 `detailImages`와 `detailHtml`도 함께 유지하며 서버에서 순서에 따라 다시 계산합니다. 기존 이미지 전용 상품과 HTML만 보유한 상품도 읽을 수 있습니다. 기존 자동화 JSON을 사용하므로 DB 스키마 변경은 없습니다.
- 연속한 이미지는 기존 중앙 정렬 HTML 형식을 사용하고 텍스트 블록은 원문 그대로 이어 붙입니다. 텍스트에 줄바꿈을 추가하거나 자동 HTML 변환을 하지 않습니다.
- 실행기는 텍스트가 포함된 상세페이지를 고도몰 편집기의 HTML 원문 모드에 입력하고, 제출 필드 동기화 뒤에도 원문을 보존합니다. 입력 결과가 달라지면 등록을 중단합니다.
- 저장 확인에 재고 설정 대조를 추가했습니다. 재고 설정이 없는 과거 작업의 읽기 전용 복구와 기존 중복 등록 방지·동시 변경 검사는 유지합니다.
- 웹에서는 실행기 1.1.0 미만으로 자동 등록을 시작할 때 업데이트를 안내합니다.

- 로컬 웹 데모에서 신규 상품의 무한정 판매·0개 기본값과 수량 입력 비활성화를 확인했습니다. 재고량에 따름·7개를 설정하고 이미지 2개 사이에 원문 HTML을 넣어 순서를 변경했습니다. 저장·새로고침·재로그인 뒤에도 수량, 원문, 순서를 유지했습니다. 테스트 이미지 주소의 실제 파일 존재 여부는 검증 범위에 포함하지 않았습니다.
- 패키징한 Mac 앱에서 같은 재고 기본값과 실제 키보드로 7개 수량 입력, 원문 HTML 입력, 텍스트 순서 변경을 직접 확인했습니다. 검증용 신규 상품 초안은 취소했으며 운영 상품 데이터는 저장하지 않았습니다.

# 저장 후 자동 상품 검색 제거 — 2026-10-06

## 변경 요청과 원인

사용자는 상품별 등록 후 목록 검색·대조를 제거하고 최종 상품 검수를 직접 진행하기로 했습니다. 변경 전 실행기는 모델명 `PF12 MK2`로 상품명을 검색했습니다. 고도몰에 실제 저장된 상품명에는 `PF12+MK2`가 포함돼 검색 결과가 0건이었고, 저장 후에도 작업이 `needs_review`로 멈췄습니다. PF8도 같은 모델명 차이가 있었으며 해당 작업의 마지막 로그에는 조회 탭이 닫혔다는 오류가 남았습니다.

## 적용 동작

- 등록 준비에서 저장 전 목록 스냅샷 검색을 제거했습니다.
- 저장 버튼은 한 번만 누릅니다. 해당 몰의 폼 저장 POST 응답과 저장 완료 문구 또는 정상적인 상품 목록 이동을 확인합니다.
- 저장 후 검색 탭 생성, 상품명 검색, 목록 반복 조회, 상품 상세 가격·재고·카테고리 대조를 실행하지 않습니다. 고도몰 자체의 저장 후 화면 이동은 유지됩니다.
- 응답에 상품번호가 명확히 있으면 기록하고, 없으면 번호를 비워 둡니다. 서버는 원래 실행 버전·시각과 함께 전달된 저장 완료 응답으로 완료 상태를 반영합니다. 최종 검수 필요 안내를 기록합니다.
- 단순 HTTP 200, 저장 버튼 클릭, 저장 확인 질문만으로 완료 처리하지 않습니다. 명확한 오류·응답 없음·동기화 실패는 중단하며 재저장하지 않습니다.
- 응답을 확인한 뒤 서버 동기화만 실패했다면 재확인은 결과 동기화만 수행합니다. 과거 불확실한 저장에 대한 명시적 복구 기능은 별도로 유지하며, 알려진 상품번호로 검색할 때 모델명을 사용하지 않게 수정했습니다.

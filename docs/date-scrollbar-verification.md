# 2026-10-02 날짜 표시·스크롤바 업데이트

Mac 앱 0.2.6에서 작성일 입력과 목록 날짜를 `yyyy/mm/dd`로 통일했다. 직접 입력과 기본 달력 선택을 유지하며, 저장하는 날짜는 기존 `yyyy-mm-dd` 형식이다. 존재하지 않는 날짜는 반영하지 않고 편집을 마치면 기존 날짜로 복원한다.

스크롤바는 8px의 투명 트랙과 옅은 회색 손잡이를 사용한다. 본문·팝업·사이드바·가로 표에서 스크롤하거나 가장자리에 마우스를 가져가면 표시하고, 사용이 끝나면 약 900ms 후 숨긴다. 기본 스크롤 동작과 고대비 모드를 유지한다.

## 검증

- 빌드 및 기존 테스트 65개 통과.
- Mac 실행기·앱 테스트 5개 통과.
- 분리된 Mac UI 테스트 통과: 날짜 표시, 윤년 날짜 저장, 잘못된 날짜 복원, 달력 변경, 저장 후 재열기, 본문·팝업 스크롤바 표시와 자동 숨김, 팝업 가장자리 접근을 검증했다.
- 설치된 앱의 기존 로그인과 실행기 연결이 복원됐다.
- 실제 `261002-록스톤 신제품 등록` 리스트에서 작성일 `2026/10/02`와 기본 달력 열기를 확인했다. 달력은 날짜를 바꾸지 않고 닫았으며 리스트는 저장 완료 상태를 유지했다.
- 설치본과 패키지의 화면 파일이 같으며, 패키지의 75개 화면 자산은 검증한 빌드와 일치한다. 설치본과 패키지의 서명 검증을 통과했다.

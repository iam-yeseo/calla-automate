# CALLA 0.5.3 · 선택 메뉴와 날짜 캘린더

2026-10-12, 제공된 `dropdown.txt`와 `calender.txt`를 기반으로 웹과 Mac 앱의 선택 컨트롤을 공통 CALLA 디자인으로 적용했다. 기존 React/TypeScript와 CSS 구조에 맞추어 구현하며 추가 라이브러리 없이 Pretendard, 핑크 선택 강조, 흰색 팝업과 둥근 테두리를 사용한다.

페이지당 표시 개수는 124 × 36px로 고정해 가로 전체로 늘어나는 문제를 해결했다. 필터는 내용에 맞는 폭을 사용하고, 폼 안의 선택 메뉴는 필드 폭을 따른다. 선택 옵션은 체크 표시, 화살표 회전, 펼침 애니메이션과 키보드 탐색을 제공한다. 캘린더는 한국어 요일, 월·연도 바로 선택, 오늘 선택과 직접 입력을 지원한다. 날짜 표시 `yyyy/mm/dd`, 저장 `yyyy-mm-dd`, 유효하지 않은 입력의 기존 날짜 복원을 유지한다.

공통 팝업은 모달의 DOM 안에 남으면서 브라우저 최상위 레이어로 표시해 스크롤 영역에 잘리지 않는다. 공간이 부족하면 위로 열고, 창·스크롤 변경에 맞추어 위치를 다시 계산한다. Escape는 팝업만 닫고 기존 버튼으로 포커스를 되돌린다. 읽기 전용·비활성 필드와 저장 중 fieldset 잠금도 유지한다.

## 검증

- TypeScript 검사와 프로덕션 빌드 통과.
- 기존 데이터·API 테스트 129개, 데스크톱 기본 테스트 6개 통과.
- UI 시나리오 12개 검증: 웹·Electron의 상품 흐름, 등록 전 검토, 쇼핑몰별 데이터 구분, 선택 전달, 새 컨트롤의 키보드·비활성 상태·팝업 배치·윤년과 월 이동을 확인했다. 전체 실행에서 기능 검증 이후 발생한 Electron 임시 폴더 정리 오류는 기존 다른 테스트와 같은 재시도 설정으로 보완했고, 해당 시나리오 재검증이 통과했다.
- 운영 웹 `https://cauto.yeseo.im`의 루트와 `/api/config` HTTP 200 확인. 배포된 초기 JS/CSS가 로컬 최종 빌드와 정확히 일치한다. Worker 버전 `b29d0bbd-c226-4176-a205-5a134627803e`, 기존 변수와 비밀키를 유지해 배포했다.
- 운영 웹의 실제 상품 리스트에서 메뉴를 열어 124 × 36px 크기와 선택 강조를 확인했다. 캘린더는 기존 작성일로 열고 변경 없이 닫았다.
- `~/Applications/CALLA.app` 0.5.3 설치 완료. 기존 로그인과 11개 리스트를 확인하고 실제 6개 상품 리스트에서 새 드롭다운과 캘린더를 열어 시각·접근성 상태를 확인했다. 작성일과 저장 완료 상태를 유지한 채 닫았다.
- 설치본·배포 패키지·ZIP의 `app.asar` 일치, 화면 파일 93개 일치, 설치본과 패키지 서명 검증 통과.

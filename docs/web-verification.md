# 웹 구현 검수 — 2026-09-30

## 로컬 검증 결과

- TypeScript 검사와 Vite 프로덕션 빌드 통과.
- Node 테스트 37개 통과: 기존 상품 계약, XLSX/CSV, 권한 검사, 원자적 등록 claim, 완료 상태, 버전 기반 중단 해제.
- Python 실행기 테스트 20개 통과: 검토 모드, 수동 로그인 대기, 토큰 갱신, 중복 방지, 저장 불명확 시 중단, 정가 null/0 처리, 실행 중 상품 변경 감지.
- Cloudflare Worker `deploy --dry-run` 통과. 실제 배포는 하지 않음.
- Chrome에서 관리자·뷰어 예시 데이터로 기능 검수. 실제 Supabase/고도몰 쓰기 없음.

## 브라우저에서 확인한 동작

1. 상품 편집 취소 후 원문 유지, HTML 상품명 저장 후 다시 열어 원문 확인.
2. 이미지 파일명·분할 수·폴더에 따른 상세 이미지 주소와 HTML 생성.
3. 새 리스트/상품 생성, 0원과 빈 가격 구분 저장.
4. 뷰어 화면의 생성·편집·실행 제어 제한 및 읽기 전용 상품 모달.
5. 미저장 상태에서 뒤로가기 → 취소 시 URL·초안 유지, 확인 시 정상 이동.
6. 수동 완료/해제 후 채널별 등록 결과 유지.
7. 상품 인덱싱의 ROXTONE 검색 결과 확인.
8. 390×844 모바일 목록과 스크롤 모달, 원래 데스크톱 크기로 복원.
9. 코드 수정 중 발생한 Fast Refresh 의존성 배열 경고 3건은 새로고침 후 재발하지 않음.

화면 기록: [데스크톱](screenshots/dashboard-desktop.jpg), [모바일](screenshots/dashboard-mobile.jpg). 미리보기의 검수용 리스트는 로컬 예시 데이터입니다.

## 운영 연결 후 남은 검증

- 관리자 이메일/실계정 및 뷰어 계정 역할 설정, Worker 비밀키 연결.
- 인증된 실계정으로 조회·저장·썸네일 업로드·뷰어 쓰기 거부 검수.
- Chrome에서 수동 로그인 후 고도몰 검토 모드의 실제 입력 필드 확인. 실제 상품 등록은 아직 실행하지 않음.
- 새 GitHub 저장소 연결과 Worker 배포, 기존 익명 API 정책 전환 및 도메인 교체.

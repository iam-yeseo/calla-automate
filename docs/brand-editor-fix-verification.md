# 브랜드 중복 경고·HTML 입력 오류 수정 — 2026-10-06

## 원인과 수정

실패 기록에서 15:59~16:02 KST에 시도한 AUDIOCENTER 상품들이 저장 이전의 상세설명 입력 단계에서 `HTML 원문 입력 모드를 열 수 없습니다` 오류로 중단됨을 확인했습니다. 실제 고도몰이 제공하는 SmartEditor2의 원문 모드 식별자는 `HTMLSrc`인데 실행기 1.1.0은 `HTML`을 사용하고 있었습니다. 모드 전환과 제출 시 원문 보존 훅의 조건을 모두 수정했습니다. 태그·엔티티·공백은 유지하며, 브라우저 textarea의 CRLF/CR → LF 줄바꿈 정규화는 검증 시 허용합니다. 사용자가 원문을 직접 수정하면 수정한 내용이 제출 필드에 반영됩니다.

입력이 실패한 뒤에도 등록 화면 URL이 같다는 이유로 기존 폼을 재사용했습니다. 그 폼에 이미 선택된 AUDIOCENTER를 다시 추가할 때 고도몰의 중복 검사(`info_brand_<code>`)가 첨부 화면의 경고를 발생시켰습니다. 상품 준비를 시작할 때마다 새 폼을 불러오도록 변경하여 브랜드뿐 아니라 이전 카테고리·원산지·이미지·상세설명·열린 모달도 다음 상품으로 남지 않게 했습니다. 저장 결과가 불확실한 작업은 기존 실행기의 중단·복구 정책을 유지합니다.

브랜드 선택은 해당 검색창에 범위를 한정하고, 검색 결과 DOM 교체를 기다린 뒤 정확히 일치하는 이름 한 개만 선택합니다. 검색과 적용 버튼은 각각 한 번만 누릅니다. 이미 이름과 코드가 적용된 브랜드는 다시 추가하지 않습니다. 이름이 일치하지 않거나 같은 이름이 여러 개이면 해당 상품의 입력을 실패 처리하며, 선택 후에는 브랜드명과 실제 코드를 모두 대조합니다.

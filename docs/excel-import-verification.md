# XLSX 가져오기 수정 검증 — 0.2.2

검증일: 2026-10-02. 웹과 Mac 앱이 공유하는 가져오기 및 리스트 생성 화면을 수정했습니다.

## 원인과 변경

첨부된 `260908-신제품 작업 리스트(록스톤).xlsx`의 첫 시트 `230110`은 3~5행에 병합된 3줄 제목을 사용합니다. 기존 가져오기는 이 제목을 모두 구분하지 못해 제목의 일부를 상품 행으로 해석하거나 서로 다른 열을 같은 항목에 연결했습니다.

- 병합 셀의 시작 행과 열별 제목 경로를 사용해 최대 5줄의 제목을 구분합니다. 품명 기본/스마트스토어 전용, 등록 여부, 자사몰 가격, 도매 베이직/마스터 가격을 각각 연결합니다.
- 내용·이미지 사용 여부 텍스트·하이퍼링크·수식의 저장된 계산 결과를 보존합니다. 원본에 없는 가격은 0으로 채우지 않습니다.
- 상품명 없이 모델명 또는 다른 채널 상품명만 있는 행은 편집할 수 있는 초안으로 가져옵니다. 실제 등록 가능 여부는 기존 필수 정보 검사를 유지합니다.
- 파일 선택 즉시 상품 수, 읽은 시트와 제목 줄 수, 상품명 누락을 표시합니다. 잘못된 가격이나 실제로 충돌하는 중복 열은 계속 오류로 안내합니다.
- 파일 확인 중이거나 오류가 있으면 리스트 생성을 막고, 파일 변경 시 이전 확인 결과를 사용하지 않습니다.

- 수정 전후 원본 SHA-256: `02f86b7278b08136e6e728bd0f6a3c1fac1929439fa7b62b621735ddb00d6027`.
- 제목 3~5행, 상품 6~11행을 구분하여 **6개 상품**, 상품명 없는 **5개 초안**을 인식했습니다.
- 자사몰·도매·스마트스토어 가격과 빈 가격을 원본 셀 값과 대조했습니다. 이미지 사용 여부 텍스트를 읽으며, 엑셀에 삽입된 이미지 추출을 추가한 것은 아닙니다.
- 설치된 `CALLA.app`에 실제 첨부 파일을 선택해 “6개 상품을 인식했습니다”, “3줄 제목”, “상품명 없는 5개” 안내와 활성화된 리스트 만들기 버튼을 확인했습니다.
- 운영 데이터베이스의 기존 저장 함수와 제약 조건을 읽기 전용으로 확인했습니다. 상품명이 빈 초안은 기존 저장 형식과 호환됩니다.

## 자동 검증

- `npm test`: **60개 통과**. 3줄 병합 제목, 모든 열의 연결, 상품명 누락 초안, 실제 중복 열 충돌, 가격 오류의 행 번호, 빈 값/0원, 수식·링크 등을 포함합니다.

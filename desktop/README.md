# CALLA for Mac · 0.6.3

상품 준비와 고도몰 소매·도매 운영을 하나의 macOS 앱에서 사용합니다. 웹 **https://cauto.yeseo.im**과 같은 계정·상품·설정 데이터를 사용합니다.

0.6.1에서는 등록 전 검토와 등록 작업 이력을 쇼핑몰 상품 화면 형태로 확인합니다. 실제 전송 내용의 썸네일·브랜드·카테고리·상품명·정가/판매가·제조사·원산지·배송비와 PC/모바일 상세페이지를 표시합니다. 배송비는 관리자에서 확인한 정책과 확인일, 배송 방식별 차이와 추가요금을 함께 표시합니다. 자동 등록 검토에서는 상품·몰별 탭으로 전환합니다.

0.6.3에서는 리스트의 소매·도매 등록 완료 결과를 준비 상태와 같은 체크표시가 있는 초록 `등록완료` 태그로 표시합니다. 태그를 누르면 해당 상품 페이지가 열립니다.

## 새 디자인

[Figma의 06 · CALLA-AUTOMATE 새 디자인](https://www.figma.com/design/2eInZ8qvqO2kI88cxofumv/?node-id=30-1293)을 적용했습니다. 64px 헤더, 260px 사이드바와 60px 접힘 상태, Pretendard 14px 본문, 26px 제목, 핑크 주 행동과 연핑크 선택 상태를 사용합니다. 작은 Mac 창에서는 사이드바가 접히며 본문과 표 내부가 스크롤됩니다. 모달 제목과 하단 버튼은 항상 접근할 수 있습니다.

0.5.3에서 선택 메뉴와 날짜 캘린더를 공통 CALLA 디자인으로 통일했습니다. 페이지당 표시 개수는 124px로 줄이고, 선택 메뉴는 연핑크 강조·체크 표시·키보드 탐색을 제공합니다. 캘린더는 월·연도 바로 선택, 오늘 선택, 직접 날짜 입력을 지원하며 웹과 같은 동작을 사용합니다.

## 사용하기

1. `release/mac-arm64/CALLA.app` 또는 `~/Applications/CALLA.app`을 엽니다.
2. 기존 계정으로 로그인합니다. 저장된 로그인은 계속 사용합니다.
3. **리스트 만들기**로 빈 리스트를 만들거나 Excel 파일을 가져옵니다.
4. **상품 추가**에서 기본 설정·이미지 설정을 편집하고 **목록에 반영**합니다.
5. 리스트의 **저장**을 눌러 상품을 저장합니다. 반영만 한 초안은 아직 저장되지 않습니다.
6. 저장된 상품을 선택하고 **등록 전 검토**에서 소매·도매 설정을 확인합니다. API 검증 후 확인 체크와 등록 버튼을 눌러야 실제 등록됩니다.

0.4.0부터 고도몰 공식 API만 사용합니다. Python, 별도 로컬 실행기, 관리자 Chrome 로그인은 필요 없습니다. 스마트스토어 자동 등록과 고도몰 상품 삭제는 제공하지 않습니다. 원격 변경은 상품 조회의 변경 전·후 검토를 거쳐 실행합니다.

0.5.1은 원산지 선택, 도매 정가 자동 연동·직접 입력, 자동 등록 전체선택, 썸네일, 페이지당 표시 개수와 간소화한 조회 상세를 제공합니다. 상품명은 HTML을 포함해 기본 상품명 텍스트로 그대로 전송합니다. 마우스 옆 버튼과 **⌘[ / ⌘]**로 뒤로·앞으로 이동할 수 있으며 미저장 초안은 확인 후 이동합니다.

창 닫기는 창을 숨기며 Dock 또는 메뉴 막대에서 다시 열 수 있습니다. **⌘Q**는 앱을 종료합니다. 저장되지 않은 변경이나 등록 진행 중에는 종료 확인을 표시합니다. 단축키 **⌘S** 저장, **⌘R** 최신 데이터, **⌘,** 동기화, **⌘W** 창 숨기기를 지원합니다.

## 데이터와 보안

상품 UUID, 가격 5종의 빈 값과 0, 재고, 상품명 원문, 이미지·텍스트·HTML 혼합 블록 순서, 완료 표시와 몰별 등록 결과를 유지합니다. 날짜는 `yyyy/mm/dd`이며 스크롤바는 사용 중에만 표시됩니다. 조회 전용 사용자는 원문을 확인할 수 있으나 저장·등록할 수 없습니다.

화면은 앱에 포함된 `calla://app` 파일을 사용하고 API는 `https://cauto.yeseo.im`에 연결합니다. 서비스 키를 앱에 넣지 않습니다. 로그인 세션은 Electron safeStorage로 암호화해 `~/Library/Application Support/CALLA/session.enc`에 저장합니다. Node integration은 꺼져 있고 sandbox와 context isolation을 유지합니다.

## 빌드·검증

```sh
npm run build
npm test
npm run test:desktop
npm run test:desktop:ui
npm run desktop:package
```

출력은 `release/mac-arm64/CALLA.app`, 보관본은 `release/CALLA-0.6.3-mac-arm64.zip`입니다. Apple Silicon·macOS 13 이상을 대상으로 하며 ad-hoc 서명으로 개인 Mac에서 사용합니다. [0.5.0 디자인 검증 기록](../docs/redesign-050-verification.md)과 [API 동작 기록](../docs/godomall-040-worklog.md)을 참고하세요.
